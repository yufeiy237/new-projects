这是我目前整合好的网页分享包，里面包含网页、样式、动效脚本和图片，Contribution 和 Results 的主要内容已经填好了，其他部分还有一些框架和占位内容。

打开方式：

1. 先把整个 ZIP 解压，不要直接在压缩包里打开网页。
2. 电脑安装了 Python 的话，双击「打开完整网页.cmd」，浏览器就会自动打开 Contribution。预览时保留启动窗口，关掉窗口网页服务也会停止。
3. 没有 Python 的话，可以用 VS Code 打开整个文件夹，再通过 Live Server 预览。

需要保留文件夹里的所有文件和原来的目录结构，不要只拿一个 HTML 文件，否则可能丢失样式、图片和动效。

Results 第六部分的图片目前还没有，所以页面里保留了占位。
