网页分享包使用说明

本文件夹包含目前网站全部 HTML、CSS、JavaScript、图片和 assets 文件夹。

给队友看：
1. 将整个 ZIP 发给队友。
2. 队友先解压整个 ZIP，不要在压缩包内直接打开。
3. 双击 Contribution.html 或 Results.html 查看；Home.html 是现有首页。
4. 如浏览器直接打开时某些效果不正常，用 VS Code 打开整个文件夹，再使用 Live Server 打开页面。
5. 队友不需要安装 Copilot、Codex 或其他制作工具插件。

不要只发送 HTML，不要改动文件之间的目录关系。CSS 控制样式，JS 控制交互，图片和 assets 提供图形。
本包保留其他页面，以便现有导航链接能打开；其中部分页面仍是框架或占位内容。
Results 第六部分仍保留原有图片占位；打包不会补充缺失的科学图片。

公网发布：
这个 ZIP 是分享和迁移用的源文件包，不是已经上线的网站。
上传到 iGEM GitLab 前，需要适配 wiki/pages 模板、static 中的 CSS/JS，并将图片按要求上传到 iGEM 官方资源服务器。
不要把此包直接覆盖整个队伍仓库，也不要覆盖原仓库的部署配置。

完整预览：在已安装 Python 的 Windows 电脑上，双击 打开完整网页.cmd。浏览器会自动打开 Contribution。保留启动窗口，关闭窗口即停止预览。必须先解压全部文件。若尚未安装 Python，可使用 VS Code Live Server。
